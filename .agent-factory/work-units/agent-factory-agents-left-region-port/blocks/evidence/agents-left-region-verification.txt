수용 기준 검토
- 독립 agents manifest가 publisher agent-factory와 engines.vscode ^1.129.0을 사용한다.
- native viewsContainers.activitybar container가 실제 24x24 currentColor SVG를 사용한다.
- Explorer는 vscode.workspace.workspaceFolders, workspace.fs.readDirectory 및 native TreeView를 사용한다.
- Explorer 모델은 생성 디렉터리를 제외하고 디렉터리를 파일보다 먼저 정렬한다.
- Chat Webview View는 Main/Workflow 탭, 로컬 세션 생성·선택, 세션별 draft 보존을 제공한다.
- Chat은 fetch, WebSocket, EventSource, postMessage 또는 전송 버튼을 제공하지 않는다.
- Webview는 nonce 기반 CSP, 빈 localResourceRoots, VS Code theme token, 키보드 탭 탐색과 visible focus를 사용한다.
- 사용자 아이콘은 Activity Bar SVG asset 및 inline SVG로만 구현했다.
- ../web은 저장소 밖 읽기 전용 원본으로 유지했고 workspace 경로에는 변경이 없다.
